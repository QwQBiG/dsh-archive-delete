# 验收与验证

简体中文 · [English](acceptance.md)

## 证据规则

数据变更夹具使用临时目录及已知合成会话，未对用户主 profile、项目文件或现有插件执行数据操作。单元测试通过、作者声明兼容范围和实际宿主／界面集成运行，分别记录为不同证据。

场景表定义验收目标；下方验证记录说明实际执行的范围、精确命令、宿主／运行时版本、数量和重要限制。不能凭源码阅读将未执行项写成通过。

## 必须覆盖的场景

| 范围 | 场景 | 预期结果 |
| --- | --- | --- |
| 冷归档会话 | 同一进程内预览、移动、恢复和永久清除，并跨重启边界复测 | 日志字节与宿主登记符合每个可见状态；永久清除不要求重启 |
| 范围 | 请求未归档或未知会话 | 源数据不变，明确拒绝／跳过 |
| 所有权 | 母会话含专属子代理与独立 fork | 子代理随母会话移动，fork 保持完整且可读取 |
| 活动 | 运行回合、子代理、后台任务、定时任务或待交互 | 不移动，也不当作闲置任务排队 |
| 本宿主写锁 | 本轮曾打开且完全闲置的托管会话 | 新手动确认后可释放原生生命周期并立即移动；缺少安全释放能力时保留原日志并待处理 |
| 外部写锁 | 其他进程占用 `session.lock` | 拒绝且不抢锁 |
| 取消待处理 | 取消后重启 | 目标不被移动 |
| 待处理漂移 | 排队后新增内容或取消归档 | 旧请求不移动变化后的数据 |
| 待处理重试 | 取消等待并重新核对，关闭／取消／确认新预览，或核对结果不明的响应 | 明确结束旧排队；须重新确认，较晚响应不能重新打开已关闭弹窗 |
| 闲置释放保护 | 运行或维护阶段、待处理输入、未知生命周期、清理函数不明确，或存在组外运行时子项 | 拒绝清理／移动，保留工作及独立关系 |
| 释放漂移 | 原生清理失败，或移动前内容／归档状态变化 | 不移动已变化或未核实的数据；报告原因并要求重新核对 |
| 启动重放 | 旧队列请求遇到已加载会话 | 不触发新手动闲置释放路径，保留受保护的待处理行为 |
| 批量 | 混合可执行、待处理、跳过、失败目标 | 逐项状态与计数准确，仅重试失败项 |
| 幂等 | 连点、重复请求、响应丢失 | 一次转换，结果稳定 |
| 确认 | 取消移动／清除确认框 | 不发生数据变更 |
| 路径 | 越界、会话／项目符号链接、根目录不符 | 拒绝，父目录、邻居与项目文件完整 |
| Windows 存储 | 本地路径、大小写别名、UNC／设备路径、junction 及原生锁竞争 | 接受安全本地身份，拒绝重定向／远程路径及被占用的原／迁移后位置 |
| Desktop CLI 注册 | 安装打包依赖、检查 bundle、注册一次并加载 | 不把包安装当作启用，保留既有 bundle 且不重复登记 |
| 同卷 | 回收站位于其他磁盘卷 | 拒绝，不采用复制后删除兜底 |
| 工件准入 | 未知文件或非法清单 | 拒绝变更／清除，数据保留 |
| 恢复冲突 | 原目标目录重新出现 | 不覆盖，回收站仍可恢复 |
| 工作区缺失 | 原登记已不存在 | 恢复为未分组的已归档会话，不建项目目录 |
| 共享文件 | 共享附件、spill、项目目录、其他插件缓存 | 移动、恢复、清除全程保持原样 |
| 崩溃恢复 | 每个移动／登记边界前后注入故障 | 状态可协调，无假成功、无重复转换 |
| 部分清除 | 已删部分文件后故障 | 报告实际未完成状态，不承诺完整恢复 |
| 只读列表 | 打开列表与影响预览 | 不激活会话，不改写原生日志与登记 |
| 宿主门禁 | DSH 版本、平台、后端或能力不符 | 界面说明不支持，禁用数据操作 |
| 原生界面 | 菜单、插件详情按钮、页签、选择、确认、结果 | 在隔离 DSH 内可见，不弹外部管理窗口 |
| 无障碍／语言 | 键盘、中文／英文、明暗主题 | 标签可读，范围明确，控件可用 |
| 安装包 | 隔离 profile 中 GitHub 安装／更新／卸载 | 产物可加载，无依赖 prepare 构建，卸载保留回收站 |
| 发行包 | Release 资产仅含声明文件；下载匹配校验文件 | 不包含源码／测试／CI；安装无需构建，校验匹配 |
| 升级与卸载 | 用新固定 URL 替换依赖，核对 bundle，卸载后清理残留条目 | 不重复登记，保留其他 profile 字段、回收站与恢复记录 |
| Doctor | 核对注册、产物、宿主版本及既有目录权限 | 只读；不创建／修复目录，不把离线检查当作当前进程已加载 |
| 加载信号 | 完成恢复和 API 注册后，或启动拒绝／失败 | 成功才输出带插件／宿主版本及回收站路径的加载日志 |
| 扫描开始／取消 | 打开弹窗／页签、选择工作区、开始／取消，扫描时切换页签或关闭 | 不自动遍历；仅明确开始后扫描，取消／较晚结果不覆盖当前界面 |
| 存储来源解析 | DSH home 外配置根目录、嵌套分类、缺失服务及内存搜索索引 | 解析实际拥有者，排除已知子根，只测量配置的索引文件；未知／不可用不显示为零 |
| 存储计量 | 硬链接、重复／重叠根及未知文件身份 | 全局逻辑字节将已核实重复项计一次，说明分类／目录别名及不完整身份检查 |
| 扫描上限 | 条目／时间／深度上限、无法读取、并发写入／移除 | 有限的流式元数据扫描，明确部分状态及观察时间；不读内容，不运行 Git／程序 |
| 扫描路径安全 | 符号链接／junction、祖先重定向、跨卷子项或特殊文件 | 不跟随重定向，不统计外部目标，保留夹具字节 |
| 工作区范围 | 登记 ID、过期成员资格／路径、磁盘根、用户目录／祖先或受保护宿主数据 | 只扫描一个当前准入的项目，拒绝不安全根并排除已知宿主数据子目录 |
| 工作区来源 | 大项目文件或暗示生成产物的文件名 | 显示来源未知，不提供 AI 分类、删除操作或清理权限 |
| 当前回收站大小 | 移入后文件变化，或有日志的部分永久清除（含整个成员已移除） | 列表／预览按已校验指纹观察显示剩余字节，不沿用历史清单合计；漂移使旧确认失效 |
| 排序 | 跨分页边界切换默认／按大小排序 | 可见顺序稳定，回第一页并清除旧选择／预览，待处理控件保留保护 |
| 只读保留 | 扫描附件、缓存、spill、profile、项目文件及回执 | 不执行清理或自动回执过期，所有内容保持原样 |
| GitHub 发行检查 | 稳定新版、精确宿主／平台兼容、发行／候选上限、网络／限流失败 | 只读元数据；成功缓存一天、手动间隔一分钟、失败一小时重试；不把失败当作已是最新，也不自动安装 |
| 更新完整性 | ID／SHA／元数据变化、不可信重定向、超限 gzip／tar、越界／链接／重复项、钩子／依赖／peer | 原生安装前拒绝；须有重新匹配的服务端发行身份及已验证包身份／预编译文件 |
| 更新准入 | 同包且归属 profile、重复确认、请求重放、已接受归档工作 | 仅通过原生管理器更新当前 profile；等待／暂停归档变更，一次安装，保留请求身份 |
| 更新恢复 | 缓存／运行版本差异、响应丢失、卸载／重载、激活失败 | 按 profile 独立保存检查／安装日志；核对已安装状态，保留已校验文件缓存，保护不明确／待重启状态；不保证完整激活回滚 |
| 更新界面 | 详情／弹窗卡片、说明、查看／确认／取消、过期响应 | 显示运行／安装版本，以文本显示说明；仅检查或打开界面不会安装 |
| 文档 | 链接、命令与版本引用 | 相对目标存在，记载的命令及版本一致 |

## 验证命令

```sh
pnpm verify
pnpm pack --pack-destination artifacts
node scripts/release-artifacts.mjs artifacts
node --import tsx scripts/check-update-package.mjs artifacts
node scripts/verify-package-lifecycle.mjs ./artifacts/qwqbig-dsh-archive-delete-0.0.1.tgz
```

`verify` 包含构建／类型检查、单元测试、原生集成、文档及打包校验。使用 Node 24 或更新版本；记录中的本地运行通过 `PATH` 使用 Desktop 自带的 Node／pnpm。包生命周期命令在 `pack` 后独立执行。

### 运行功能覆盖

- 真实 JSONL／登记表移入、归档状态恢复和永久清除，在适用恢复时保留原生日志字节及登记一致性。母会话与专属子代理成组处理，独立 fork、共享附件和项目文件保持完整。
- 真正工厂新建的闲置代理覆盖内存省略／磁盘默认零的委派深度差异。原生生命周期释放、新指纹及正常写锁允许立即移入和清除；真实元数据变化、维护操作、待处理输入、活动工作、外部写入及不确定归属仍受保护。
- 持久操作／请求日志覆盖中断移入／恢复／清除、意图／结果写入失败、重复请求、部分清除、启动重放及取消等待／内容变化。未知文件、路径越界、符号链接、junction、跨卷布局及恢复冲突均安全拒绝。
- 只读存储扫描使用实际配置来源及明确工作区 ID，去重已验证身份，限制工作量、支持取消，并说明不可用或部分结果；不推断 AI 来源，不扩大到项目文件、共享附件、spill 或缓存的删除权限。
- 更新检查覆盖兼容稳定版、每日／手动／失败缓存、固定来源、受限下载、固定元数据、SHA-256、严格 tar／包准入、显式确认、按 profile 保存回执、原生管理器失败及安装／重启对账。恶意路径／链接、钩子和意外运行依赖会被拒绝。
- 界面检查覆盖选择／分页／页签／排序、核对／取消／确认、过期响应、本地化结果、紧凑版本信息及归档确认时隐藏更新控件。Doctor 和包生命周期区分已安装文件、bundle 登记与实际响应的 owner API。

### 桌面证据

通过 APFS 克隆复用已安装 macOS 应用，使用独立 home/profile/userData 及已知合成数据。仅 QA 使用的初始化／标题／首次使用页显示钩子保留原生网关鉴权；未使用真实凭据／历史或模型调用，没有下载应用。复制外壳继承本机改动，不作为原始外壳证据。

原生管理流程显示紧凑版本／状态／检查／详情控件。工厂新建且仍由宿主持有的闲置会话预览显示释放尝试，并隐藏更新控件。确认移入返回成功一项、无待处理／失败及回收站一项；获用户确认后的图形永久清除返回回收站为空、成功一项。移入及清除的宿主 PID 保持相同，项目／共享附件标记字节一致。另有已完成图形检查覆盖恢复，以及更新核对／取消／确认／激活／完全退出重开和合成数据哈希保留。这些证据描述保留的实现，不表示每次包元数据变化均新增图形运行。

### 限制

未目视／物理验证 Windows Desktop 图形界面、真实跨磁盘卷移动或整机断电；原生 Windows 集成、布局拒绝及合成／进程级恢复检查分别记录。图形取消待处理仍未验证。一次 HMR 成功不保证所有后续升级无需重启，也不保证任意激活失败均能完整回滚。兼容性限于声明的宿主／存储／操作系统能力。
