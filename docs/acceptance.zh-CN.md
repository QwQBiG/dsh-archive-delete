# 验收与验证

简体中文 · [English](acceptance.md)

## 证据规则

测试使用临时目录和合成会话，不使用用户主 `~/.dsh` 历史、项目文件或 `dsh-purge`。单元测试通过、作者声明兼容范围和实际宿主／界面集成运行，分别记录为不同证据。

初始研究提交中的实现验证状态为 **待验证**。发布前在下方记录精确命令、宿主／运行时版本、测试数量及重要限制；不能凭源码阅读将待验证项写成通过。

## 必须覆盖的场景

| 范围 | 场景 | 预期结果 |
| --- | --- | --- |
| 冷归档会话 | 预览、移动、重启、恢复、重启、清除 | 日志字节与宿主登记符合每一个可见状态 |
| 范围 | 请求未归档或未知会话 | 源数据不变，明确拒绝／跳过 |
| 所有权 | 母会话含专属子代理与独立 fork | 子代理随母会话移动，fork 保持完整且可读取 |
| 活动 | 运行回合、子代理、后台任务、定时任务或待交互 | 不移动，也不当作闲置任务排队 |
| 本宿主写锁 | 本轮曾打开的闲置会话 | 显示待处理，原日志保留，下次启动复查 |
| 外部写锁 | 其他进程占用 `session.lock` | 拒绝且不抢锁 |
| 取消待处理 | 取消后重启 | 目标不被移动 |
| 待处理漂移 | 排队后新增内容或取消归档 | 旧请求不移动变化后的数据 |
| 待处理重试 | 下次启动仍占用 | 继续待处理，不强制移动 |
| 批量 | 混合可执行、待处理、跳过、失败目标 | 逐项状态与计数准确，仅重试失败项 |
| 幂等 | 连点、重复请求、响应丢失 | 一次转换，结果稳定 |
| 确认 | 取消移动／清除确认框 | 不发生数据变更 |
| 路径 | 越界、会话／项目符号链接、根目录不符 | 拒绝，父目录、邻居与项目文件完整 |
| 同卷 | 回收站位于其他磁盘卷 | 拒绝，不采用复制后删除兜底 |
| 工件准入 | 未知文件或非法清单 | 拒绝变更／清除，数据保留 |
| 恢复冲突 | 原目标目录重新出现 | 不覆盖，回收站仍可恢复 |
| 工作区缺失 | 原登记已不存在 | 恢复为未分组的已归档会话，不建项目目录 |
| 共享文件 | 共享附件、spill、项目目录、其他插件缓存 | 移动、恢复、清除全程保持原样 |
| 崩溃恢复 | 每个移动／登记边界前后注入故障 | 状态可协调，无假成功、无重复转换 |
| 部分清除 | 已删部分文件后故障 | 报告实际未完成状态，不承诺完整恢复 |
| 只读列表 | 打开列表与影响预览 | 不激活会话，不改写原生日志与登记 |
| 宿主门禁 | DSH 版本、平台、后端或能力不符 | 界面说明不支持，禁用数据操作 |
| 原生界面 | 菜单、插件详情按钮、页签、选择、确认、结果 | 在隔离 DSH 内可见，不弹外部管理窗口 |
| 无障碍／语言 | 键盘、中文／英文、明暗主题 | 标签可读，范围明确，控件可用 |
| 安装包 | 隔离 profile 中 GitHub 安装／更新／卸载 | 产物可加载，无依赖 prepare 构建，卸载保留回收站 |
| 文档 | 中英文件与链接 | 成对存在，命令、限制、版本和发布事实等价 |

## 验证命令

```sh
pnpm verify
pnpm pack
```

`verify` 应包含构建／类型检查、单元测试、集成测试、双语文档和打包校验。必须记录实际结果及未覆盖环境；把命令列在这里不代表它已通过。
