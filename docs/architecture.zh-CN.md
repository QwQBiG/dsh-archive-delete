# 架构

简体中文 · [English](architecture.md)

## 目标与边界

插件只提供一个生命周期：**已归档 → 回收站 → 恢复为已归档，或显式永久清除**。首个目标为官方 macOS DSH Desktop `0.2.1-rc.3` 与 JSONL 持久化后端。

实时会话、工作区、活动状态和会话历史以 DSH 为准；原始日志字节是会话内容的事实来源。插件只拥有操作记录、回收站清单和原生界面贡献，不替换工作区注册表、会话后端、投影缓存或侧边栏。

## 四个模块

| 边界 | 职责 | 禁止承担的职责 |
| --- | --- | --- |
| `client` | 原生菜单、管理弹窗、选择、预览、确认与本地化结果 | 接受磁盘路径、猜测移动成功或直接修改存储 |
| `service` | 校验动作、检查完整会话组、串行转换、执行前复查、报告部分结果 | 耦合未公开的宿主字段，或无日志地修改文件系统 |
| `dsh-adapter` | 精确版本准入、列表与活动查询、专属子代理关系、规范路径、兼容写锁、登记移除与恢复 | 仅凭传入路径判断所有权，或默默接受未知宿主版本 |
| `storage` | 插件清单、持久阶段记录、同卷移动、恢复及受限永久清除 | 递归删除任意路径、覆盖冲突源目录或清理共享附件 |

共享类型集中在契约模块。服务依赖适配接口，不导入整套 DSH 运行时。因此可以用合成适配器测试真实存储转换，再由独立集成测试验证宿主边界。

## 界面与传输

在已归档会话的原生行菜单加入 **移入回收站**；插件详情增加 **管理归档与回收站**，打开双页签原生弹窗。使用 DSH 组件与模块加载机制，React 和 DSH 由宿主提供。

浏览器经 DSH 已鉴权连接网关调用 `/api/dsh-archive-delete`，请求范围保持精简：

- `list`：支持状态、归档记录、回收站记录及最近操作结果。
- `preview`：操作类型（`trash`、`restore`、`purge`）及选中 ID。
- `execute`：不透明的预览 ID 和请求 ID。
- `cancelPending`：选中会话 ID 和请求 ID。

浏览器不传入源路径或目标路径。预览包含目标、组成员、大小及可执行／待处理／阻止状态。执行时服务再次检查权威状态；预览并不授权操作已经变化的数据。

结果区分 `moved`、`pending`、`restored`、`purged`、`cancelled`、`skipped`、`failed`；批量计数由逐项结果生成。排队不等于已经移入回收站。

## 持久化与宿主一致性

插件状态放在 `<DSH_HOME>/archive-delete/`：转换日志在 `operations/`，移动中的暂存内容在 `staging/`，物理回收站在 `trash/`，请求进度与回执在 `receipts/`。实际 home 由正在运行的宿主提供。回收站必须在会话根目录之外，并处于同一磁盘卷。

一个会话组包含选中的母会话，以及明确属于它的专属子代理子孙。只有 `parentSession` 不足以证明子代理所有权，因为独立 fork 也有母会话关系。关系未知或冲突时，在任何移动前阻止整组操作。

移动文件与修改 DSH 登记属于多步操作，不是跨系统原子事务。变更前先持久化请求意图，再逐项目标写入结果；关联的操作记录保存执行进度及原登记信息，用于协调失败或中断后的状态。完成证明会保留到请求结果持久化，弥合文件提交与浏览器响应之间的空隙。移动前校验并锁住组成员；通过适配层的宿主串行写入路径更新已知登记，不直接改写 `workspace.json`。

插件不维护第二份全文或投影镜像。恢复所需元数据仅在仍可恢复时保留，并随回收站条目永久清除。不额外复制用户首条消息以补侧栏标题。独立的幂等回执保留请求／目标标识及操作结果，移除会话标题；这些回执不是会话备份。

恢复 JSON 的读写上限同为 8 MiB。初始请求意图限于 6 MiB，在任何转换开始前，为最多 100 项有长度边界的结果预留空间。元数据过大时，在写入／移动前拒绝并要求缩小批次；已准入的意图必须能在结果累积时继续写入。

## 兼容策略

首版使用精确版本门禁，不承诺全部 `0.2.x` 都兼容。版本来自当前 profile 的运行时安装锚点，不以插件固定的 peer 包版本冒充真实宿主。数据变更要求宿主版本匹配、运行于 macOS、使用 JSONL 后端、规范路径安全，且活动／写锁／登记能力齐全。无法确认时返回明确的不支持或阻止结果。

所有宿主内部结构访问集中于适配层。后续宿主变化需要明确更新适配并提供实测证据，不能只放宽版本范围。

## 范围决策

- 不自动过期清空回收站，不创建后台清理定时器或 Agent 删除工具。
- 不强制停止会话，不抢占写锁。
- 不做附件垃圾回收、spill 清理、旧第三方缓存清理、项目删除、OCR、全文搜索或跨 Agent 迁移。
- 不自建插件更新器，安装更新交由 DSH 插件管理器。
- 打开管理列表或预览不修改原生会话存储。

逐步转换规则见 [操作与恢复](operations.zh-CN.md)。
