# 操作与恢复

简体中文 · [English](operations.md)

## 状态

| 状态 | 位置 | 后续操作 |
| --- | --- | --- |
| 已归档 | 宿主原始日志 | 预览并移动 |
| 待重启处理 | 原始日志及排队请求 | 重新核对、取消或等待启动 |
| 回收站 | 插件回收站及恢复元数据 | 恢复或永久清除 |
| 失败／跳过 | 逐项结果中显示 | 查看原因并重试目标 |
| 已永久清除 | 所选日志和恢复元数据已移除 | 完成 |

批量结果分别计算成功、待处理、跳过和失败。损坏记录单独提示，健康记录继续显示。

## 确认

预览将所选 ID 解析为母会话／子代理组，显示大小、成员、可处理／尝试闲置释放／受保护数量及到期时间，有效期五分钟。内容、登记或关系变化时需重新预览。

一个预览授权一个请求，在持久意图发布前消费，发布报错时也已消费。相同请求 ID 可恢复已有意图／结果。维护状态清空活动预览并忽略较晚返回的预览响应。

## 移动与待处理请求

1. 检查归档组和活动状态。
2. 闲置的宿主受管写入器通过原生生命周期释放，再次检查组。
3. 取得成员写锁，持久化请求／操作元数据。
4. 通过暂存移动成员目录，更新原生登记并提交回收站条目。
5. 持久化逐项结果，完成终态操作日志。

写入器仍被持有时，请求保持待处理。**取消等待并重新核对** 会取消该队列并打开新预览；取消或关闭预览时，原始日志保留。启动先恢复中断操作，再对每个排队移动检查一次。内容变化或取消归档会结束旧请求，需要重新确认。

## 恢复与永久清除

恢复后，组回到原工作区的已归档状态；工作区缺失时归入未分组。目标位置已存在时，该项报告冲突。

永久清除在当前进程处理所选回收站条目，移除日志和恢复元数据，无法撤销。部分清除会报告剩余状态，支持新的显式重试；剩余组完整时才能恢复。

## 操作日志恢复

| 记录阶段 | 启动处理 |
| --- | --- |
| `moving` / `detached` / `trashed` | 协调已提交回收站条目，或将暂存回滚到原位置 |
| `restoring` | 将未完成恢复回滚至回收站 |
| `restored-metadata` / `restored` | 完成宿主登记和回收站清理 |
| `purging` / `purged` | 完成空条目清理，剩余文件报告为需显式重试 |
| `pending` | 复查原组并尝试一次排队移动 |

恢复按记录的所有权检查实际路径和写锁。有记录的清理可以接受原始空 bucket 缺失；冲突或无法读取的数据会产生诊断。报告问题时保留受影响条目及对应日志。

完成请求回执保留 ID／结果以供重放。列表通过缓存索引读取最近结果，启动时显式清理临时回执文件。

## 存储观察

存储扫描有独立的取消生命周期，结果包含观察时间、完整／部分状态、分类／类型大小和跳过项。同范围重新扫描时保留上次结果，切换范围时清空。取消扫描只作用于扫描本身。

## 更新恢复

| 状态 | 操作 |
| --- | --- |
| `installing` | 等待原生管理器，继续观察状态 |
| `installed` | 目标已安装，提示时完整重启加载 |
| `restart-required` | 完整退出并重新打开 DSH |
| `failed` | 查看诊断、核对已安装版本，再重新查看升级 |
| `interrupted` | 重新检查发行版和当前安装 |
| `unknown` | 核对安装状态或重新核对此次请求，仍不明确时完整重启 |

检查和安装日志按 profile 保存在 `updates/`，已校验安装包位于 `updates/packages/`。同请求检查原生安装状态，已记录的管理器调用不重复执行；轮询间隔从 3 秒退避到 15 秒、60 秒。

替换前排空归档操作，并暂停新变更。卸载取消尚未委托的校验，已准入安装由原生管理器继续负责。启动时核对保存的目标、已安装及已加载版本。
