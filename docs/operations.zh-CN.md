# 操作状态与崩溃恢复

简体中文 · [English](operations.md)

## 用户可见状态

| 状态 | 含义 | 后续操作 |
| --- | --- | --- |
| 已归档 | 原始日志仍在宿主存储中 | 预览并移入回收站 |
| 待移入回收站 | 用户已确认，但宿主仍持有写入器，无法安全立即释放 | 取消等待并重新核对新移动、取消请求，或下次启动重新检查 |
| 回收站 | 日志已移动，宿主登记处理完成 | 恢复或预览永久清除 |
| 失败／跳过 | 本项转换未完成，界面显示原因 | 检查后仅重试相应失败目标 |
| 已永久清除 | 选中日志及恢复元数据已从回收站移除 | 无法恢复 |

批量反馈分别报告已移动／恢复／清除、待处理、跳过和失败。待处理不能显示为已删除，文件未移动前不能声称已释放空间。

## 预览与执行

预览在宿主解析选中 ID、收集专属子代理并报告实际范围，过程只读。执行使用不透明的预览身份与请求身份，再次检查归档状态、内容、关系、活动、路径和写锁。

服务串行处理数据变更，开始前持久化请求意图，并逐项目标记录持久结果。复用请求标识会读取已记录结果，不启动第二次转换；已完成的待处理请求，之后可以补充启动时实际移动的结果。不能因为部分成员或登记更新成功，就让失败成员从可重试结果中消失。

## 移入回收站

1. 解析完整的母会话／子代理组，保存恢复元数据。
2. 拒绝未归档母会话、活动工作／交互、路径不安全或关系不明，以及外部写占用。
3. 新的手动执行中，若障碍是本宿主持有闲置会话，尝试已准入的原生生命周期清理；不关闭活动工作、维护操作、待处理输入、归属不明或外部持有的写入器。
4. 成功释放后，重新检查内容、归档状态及成员，再为完整组取得兼容独占写锁并复查。数据变化要求重新确认；缺少安全释放能力时，保存待处理请求，不移动日志。
5. 持久化准备记录，再同卷移动已确认属于会话的日志目录。
6. 通过适配层处理相应宿主登记和投影元数据，发布完整回收站条目。
7. 释放写锁并报告实际结果。中间失败记录为待回滚／恢复，不显示已移入。

写锁身份遵循各平台宿主：macOS 使用 flock，Windows 使用按路径命名的内核信号量。Windows 转换同时保留原路径与迁移后路径的锁，恢复时也保留原目标；不强制抢占写锁。

操作日志让进度可以恢复，不会把多个文件及宿主写入变成单个原子事务。每一步崩溃都必须依据记录进度和实际路径协调，不能只根据返回值假定成功。

## 待处理请求

待处理请求留在“已归档”页。转换开始前可以取消；取消和执行共用串行操作路径。**取消等待并重新核对** 会结束旧排队请求并打开新移动预览，不执行移动或永久清除。关闭／取消该预览后，旧排队保持取消，源日志保留；再次确认才尝试当前处理。取消结果不明时，必须先核对。

插件启动时先恢复中断转换，再对每个待处理移动尝试一次。重新核对内容版本、归档状态、子代理关系、路径、活动与写锁。内容变化或取消归档后要求重新确认；写锁仍被占用则继续待处理。启动重放不会调用仅供新手动确认使用的闲置释放能力。不创建定时器或后台轮询，不强制中断活动工作，也不抢锁。

## 恢复

恢复前重新校验回收站清单及所有成员。目标目录冲突时拒绝，不覆盖，也不把会话改成新身份。

母会话恢复到原工作区的已归档状态。原工作区登记已不存在时，恢复为未分组的已归档会话，不重建项目目录。专属子代理按原身份一起恢复；独立 fork 从未移动。

宿主登记成功后移除已完成条目的恢复元数据。中断恢复仍须保留可协调状态，不显示完全恢复。

## 永久清除

只能清除已经进入回收站的条目。二次显式预览与确认说明母会话及子代理日志；确认后在当前进程执行永久清除，不要求重启宿主。安全立即移动成功后，也可以在同一进程清除产生的新回收站条目。仅移除验证过的、插件拥有的回收站工件和对应恢复元数据（含保存的标题）；出现未知文件或不安全路径时阻止操作。

永久清除无法撤回已移除的字节。中途失败时保留并展示未完成状态和重试信息，不能对部分清除的组承诺完整恢复。

不安装自动过期或清空任务。共享附件、spill、项目工作目录、第三方缓存及远端副本均不在操作范围内。

## 恢复要求

| 中断位置 | 必须观察并满足的结果 |
| --- | --- |
| 准备记录持久化之前 | 不得移动日志 |
| 已准备、尚未首次移动 | 原日志保持原位，重试／恢复能取得完整目标信息 |
| 组成员移动之间 | 记录源与回收站位置，协调完整组后才接受新的数据变更 |
| 日志已移动、宿主登记未完成 | 保留日志及原登记信息，不能发布假成功 |
| 回收站已提交、响应丢失 | 列表只有一个条目，重复请求不再次移动 |
| 恢复中断 | 不覆盖任何一边，依据进度记录协调 |
| 永久清除中断 | 展示实际部分状态，支持指定重试，不虚假承诺可恢复 |

恢复只处理本插件操作记录，不顺手扫描删除宿主或其他插件的文件。具体故障注入检查见 [验收清单](acceptance.zh-CN.md)。
